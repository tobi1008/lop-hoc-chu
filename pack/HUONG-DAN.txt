LỚP HỌC CHỮ · BỘ LIVE CHO WINDOWS 10/11
=======================================

Không cần cài gì thêm. Node.js đã có sẵn trong thư mục "node".
Máy cần có Internet (giọng đọc của cô lấy từ Microsoft Edge).


1. CÀI LẦN ĐẦU
--------------
  • Chuột phải file zip → Properties → tích "Unblock" → OK (bỏ qua bước này Windows có thể chặn file .bat).
  • Chuột phải file zip → Extract All… → giải nén vào Desktop hoặc Documents.
    KHÔNG giải nén vào "C:\Program Files" (ở đó không lưu được sổ lớp và cài đặt).
  • Muốn có biểu tượng ngoài màn hình: chuột phải "Mo-Lop-Hoc-Chu.bat" → Send to → Desktop (create shortcut).
  • Nhạc nền (không bắt buộc): bỏ file nhạc vào thư mục public\assets\audio.


2. MỖI LẦN LIVE
---------------
  1) Bấm đúp "Mo-Lop-Hoc-Chu.bat".
     Một cửa sổ đen hiện ra (đó là server), vài giây sau trang điều khiển tự mở: http://localhost:3006
     → KHÔNG đóng cửa sổ đen trong lúc live. Server lỡ bị tắt thì tự bật lại sau 5 giây.
     → Nếu Windows hiện "Windows protected your PC": bấm "More info" → "Run anyway".
     → Nếu tường lửa hỏi quyền cho node.exe: bấm "Cancel" cũng được, game chỉ chạy trong máy.

  2) Mở TikTok LIVE Studio, bấm Phát trực tiếp (Go LIVE).

  3) Trang điều khiển: nhập username TikTok (không cần @) → "Kết nối".
     Báo "chưa LIVE" nghĩa là tài khoản chưa phát trực tiếp. Lần sau mở game sẽ tự kết nối.

  4) Đưa lớp học vào LIVE Studio (làm 1 lần, lần sau giữ nguyên):
       Thêm nguồn "Link" → đường dẫn  http://lvh.me:3006/?view=stage
       Bật "Turn on sound" (để có giọng cô).
       Bật "Custom resolution" → 1620 × 2880 (chữ nét hơn; 1080 × 1920 cũng được) → Apply → bấm "vừa màn hình".
     LIVE Studio không nhận chữ "localhost"; lvh.me trỏ về chính máy mình nên dùng được.
     Chỉ mở trang ?view=stage ở MỘT chỗ (LIVE Studio), mở thêm sẽ nghe hai giọng cô đè nhau.
     Dùng OBS: thêm nguồn Browser, cùng đường dẫn và khổ trên.

     CÁCH KHÁC: TÁCH TIẾNG BẰNG VB-CABLE (LIVE Studio chỉ thu tiếng lớp học, mở video khác không lọt vào live)
       • Cài VB-Cable miễn phí ở vb-audio.com/Cable, khởi động lại máy.
       • Trang điều khiển → khung "Âm thanh stage (VB-Cable)" → bấm "🪟 Mở cửa sổ stage (Edge)".
       • Ô "Phát tiếng ra" chọn "CABLE Input" (chưa thấy thì bấm "🔎 Tìm thiết bị"), dòng dưới báo ✅ là được.
       • LIVE Studio: thêm nguồn "Window capture" chọn cửa sổ Edge đó, thêm mic "CABLE Output",
         tắt âm thanh máy tính, XOÁ nguồn Link cũ (2 trang stage = 2 giọng cô đè nhau).

  5) Kết thúc: bấm "👋 Chào tạm biệt (xuống live)" ở trang điều khiển, rồi tắt live.
     Xem lại buổi live: nút "📊 Báo cáo" hoặc http://localhost:3006/bao-cao


3. THỬ TRƯỚC KHI LIVE
---------------------
  Trang điều khiển có các nút giả lập (1 bạn trả lời đúng, tặng hoa, 1000 người cùng đoán…) để xem game chạy.


4. GẶP LỖI
----------
  • Cổng 3006 đang được dùng: Lớp Học Chữ đã mở ở một cửa sổ đen khác. Dùng cửa sổ đó, hoặc đóng nó rồi mở lại.
  • Trang điều khiển không tự mở: mở trình duyệt, gõ  http://localhost:3006
  • Cô không nói: kiểm tra Internet, và đã bật "Turn on sound" trong LIVE Studio chưa.
  • Màn hình lớp học trắng hoặc đứng hình: trong LIVE Studio bấm làm mới nguồn Link.


Sổ lớp (điểm, bảng vàng tuần, báo cáo) và cài đặt lưu trong thư mục "data" và file "settings.json" cạnh file .bat.
CẬP NHẬT BẢN MỚI: trang điều khiển → khung "Cập nhật" → "🔄 Kiểm tra cập nhật" → có bản mới thì bấm
"⬇️ Cập nhật lên ..." 2 lần. Game tự tải, tự chép đè, khởi động lại vài giây; sổ lớp, cài đặt, nhạc nền giữ nguyên.
Nên cập nhật lúc KHÔNG live (tiết đang học sẽ bắt đầu lại).
Cập nhật tay (hoặc bản cũ chưa có nút này): chép thư mục "data" và file "settings.json" sang thư mục bản mới.
